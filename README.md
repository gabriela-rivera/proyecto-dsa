# Proyecto DSA

Proyecto de Despliegue de Soluciones Analíticas.

## Objetivo

Desarrollar una solución analítica que permita abordar una problemática de negocio mediante técnicas de análisis de datos y ML.

## Estructura

- `data/`: datos gestionados mediante DVC.
- `notebooks/`: notebooks de análisis y experimentación.
- `src/`: código fuente de la solución analítica.
- `docs/`: documentación y evidencias del proyecto.

## Versionamiento

- Git y GitHub: versionamiento del código y la documentación.
- DVC: versionamiento de los conjuntos de datos.
- Amazon S3: almacenamiento remoto de los datos gestionados por DVC, sujeto a la configuración del proyecto.
